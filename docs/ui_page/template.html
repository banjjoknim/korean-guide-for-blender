여는 방법 세 가지

단축키 하나만 두면 그 키를 잊는 순간 가이드로 돌아갈 길이 끊긴다. 그래서 화면에 늘 보이는 자리와, 막혔을 때 먼저 열어 보는 메뉴에도 같은 팝업을 걸어 두었다.

Control + Shift + H 어디서나 뜬다 블렌더 키맵을 훑어서 비어 있는 조합을 찾아 정했다. 처음 고른 Ctrl+Shift+G 는 이미 다른 기능이 쓰고 있었다.
N → 가이드 탭 3D 화면 오른쪽에 상주한다 단축키를 잊었을 때의 자리이다. 즐겨찾기와 지금 상황을 늘 보여 주고, 팝업을 여는 버튼에 현재 단축키를 같이 적어 둔다.
Help 메뉴 막히면 먼저 열어 보는 곳 블렌더를 처음 쓰는 사람이 도움을 찾을 때 가장 먼저 누르는 메뉴라서 세 번째 입구로 두었다.

이 짜임을 정한 제약

팝업은 버튼을 누르면 닫힌다

블렌더 팝업 안에서 버튼(오퍼레이터)을 누르면 팝업이 사라진다. 반면 속성(프로퍼티)은 눌러도 팝업이 그대로 남는다. 즐겨찾기 별표를 버튼으로 만들었다면, 별표를 누를 때마다 팝업이 닫혀서 다시 단축키를 누르고 다시 검색해야 했을 것이다.

그래서 팝업 안에 머무르며 눌러야 하는 것은 전부 속성으로 만들었고, 항목마다 상태를 담을 자리를 블렌더 창에 붙여 두었다. 팝업이 닫히는 편이 맞는 것 하나만 버튼으로 남겼다.

화면에서 눈으로 보고 잡은 것

셋 다 자동 점검은 통과한 상태였다. 실제로 띄워 보고서야 드러났다.

손으로 적어 둔 단축키가 맥에서 틀렸다

맥 블렌더는 Ctrl 자리에 Cmd 를 쓴다. 흔히 보는 Ctrl+B 가 여기서는 ⌘B 이다. 블렌더에게 직접 물어보도록 만들어 둔 덕분에 팝업에는 맞는 값이 떴고, 그 차이를 보고 손으로 적어 둔 값 25개를 바로잡았다.

블렌더에게 물어봐도 틀릴 때가 있다

하나를 여러 물체로 쪼개기 는 에디트 모드 전용인데, 오브젝트 모드에서 물어봐도 "쓸 수 있다"고 답해서 추천 목록에 끼어들었다. 지금은 사람이 적어 둔 모드 목록을 최소 조건으로 먼저 보고, 거기를 통과한 것만 블렌더에게 다시 묻는다.

자동으로 읽은 값이 늘 더 낫지는 않다

시점 돌리기 의 단축키를 블렌더에게 물었더니 Mouse/Trackpad Rotate 라고 답했는데, 이것으로는 무엇을 눌러야 할지 알 수 없다. 그래서 마우스를 끄는 조작에만 손으로 적은 값을 앞세우도록 했다.
